# Partner Email Add-On

Short welcome message for new partners receiving sandbox access.

---

## Quick Start Message

> Welcome — please start by playing in the WebRouter sandbox, then learn from the public repository: https://github.com/wildcard/web-router-playground (and the relevant `Nimbleway/web-router` package documentation).
>
> If you'd like to modify code live in the hosted environment, reply here and we'll provision the appropriate access path — either upgraded Root access after clearing host keys on the shared VM, or a dedicated VM for your evaluation.
>
> **Hosted sandbox:** https://webrouter-aisdk.exe.xyz/

---

## Usage

This message serves as a concise introduction that:
- Points partners to the hosted playground first
- Directs them to the public repository for code learning
- Sets expectations that live code access requires operator provisioning
- Provides the sandbox URL

Use this as an opening to the full [PARTNER-ACCESS.md](PARTNER-ACCESS.md) documentation.
