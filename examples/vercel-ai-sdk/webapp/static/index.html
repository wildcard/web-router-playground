How WebRouter works

The process

1
You ask in the chat
2
The Vercel AI SDK agent decides to call a tool
3
WebRouter exposes two tools, web_search and web_extract, as ordinary @ai.tool functions (build_tools(WebRouter())). No fork of the SDK.
4
A provider adapter runs the call (nimble, tavily, or exa). Same call shape, providers behind adapters.
5
The result comes back on the tool card, including which provider served it

Today is that direct path only. This preview does not include intelligent routing, a gateway, MCP, research/browse modes, or a public package launch.
