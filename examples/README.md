# Examples

Integration playgrounds for WebRouter. Preview only — not an official launch.

| Playground | Directory | Host framework | Notes |
|---|---|---|---|
| Vercel AI SDK (Python) | [`vercel-ai-sdk/`](vercel-ai-sdk/) | Vercel AI SDK for Python | Search + extract via `@ai.tool` / `build_tools(WebRouter())`; vendored wheel under `vendor/` |

Hosted Exe.dev sandbox (`https://webrouter-aisdk.exe.xyz/`) is **invite-gated**, not anonymous-public. Partners get access from the host; bring your own API keys (`.env` from `.env.example`). Never commit `.env`.
